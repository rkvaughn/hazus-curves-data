# hazus-curves-data

Prebuilt Parquet tables for the [hazus-curves](https://github.com/rkvaughn/hazus-curves)
curve browser at **https://rkvaughn.github.io/hazus-curves/**.

This repository exists only to host the data files the browser reads over HTTP range
requests. It is separated from the main repository so that cloning `hazus-curves` — or
installing the Python package from git — does not drag ~107 MB of Parquet along with it.

Nothing here is authored by hand. Every file is generated by
`scripts/build_all.py` in the main repository, from FEMA sources pinned by SHA-256.
See the main repository for provenance, licence and documentation.

Regenerate:

```bash
python scripts/build_all.py --perils fl,hu
cp dist/*.parquet /path/to/hazus-curves-data/
```
